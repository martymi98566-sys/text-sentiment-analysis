## 本次发布适配

1. 将运行时对历史过程目录的依赖替换为 100 项必要源码、元数据和模型完整性清单。
2. 把实际使用的类别边界函数独立成运行模块，保持其算法不变。
3. 启动器优先支持克隆目录中的 `.venv`；提供模型安装和 SHA256 校验工具。
4. 自训练权重单独放入 Release ZIP；公共预训练模型固定 Hugging Face 提交并核对实际远程文件哈希。
5. 保留已完成的评分辅助二分类源码、配置与对照摘要；新增提交排除独立评分预测废案、标注交接文件、原始评论库与凭据。

第一板块权重、原因模型权重、推理提示、策略阈值、提取与局部正负算法及网页美术未修改。评分辅助实验在本版仅作为训练比较材料，未替换应用的整体分类器。

## 发布副本验证

- 模型及运行文件完整性：100 项通过；三组公共模型的固定版本远程哈希通过；训练 ZIP 14 个文件逐个解压读流验证通过。
- 工程测试：31 项通过、0 失败；另有 3 项原始语料隔离测试因不分发私有标注库而明确跳过。没有把跳过项计为通过。
- Python 源码解析：48 个文件通过；当前环境 `pip check` 无冲突。
- 真实 CLI 混合短评：`The acting is excellent, but the plot is painfully predictable.` 输出整体消极，演技好评 40%、剧情差评 60%；引文、原文位置和占比校验通过。这是实测输出，不是人工改写结果。
- 真实 CLI 泛泛短评：`Great movie, highly recommended.` 输出整体积极、具体原因统计为空。
- 独立加载当前 3B 路由与自训练特异性模型：`The rapping and lyrics are dreadful.` 路由为 `sound`，两模型正常返回。
- 发布副本独立端口真实 HTTP 模型任务完成，结果、HTML 和 JSON 导出均成功；首页和脚本资源返回 200。
- 正在使用的原项目分支与索引保留；发布提交由单独索引生成，不覆盖本地研究文件。

验证复用了已安装的 Python 环境和经哈希核对的本地模型，没有重新创建空白系统并下载全部约 12GB 权重。公共下载文件与本地清单已逐项对照；安装说明提供固定依赖和 CUDA 安装步骤。公开包不附完整人工或模型标注语料，不能从此包独立重跑全部私有标注评估。

## 使用限制

仅验证英文电影评论和本机 NVIDIA CUDA/BF16 路径。原因统计的百分比表示已确认原文证据的篇幅与语气加权组成，不是情绪概率、模型准确率或用户人数比例。一般好评可能没有原因图；同一原因可同时有好坏两类证据。归类、反讽和语气仍可能出错。

源码和附件公开供下载，推理服务仍仅在本机运行。部署到公网、批量数据库处理、语种扩展和商业授权不属于本版已验证范围。详细方法、模型、数据口径和复现边界见 [技术说明](TECHNICAL_DESCRIPTION_ZH.md)。
